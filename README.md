# Build installer SIDIGIT

Repo publik ini hanya menjalankan GitHub Actions untuk membangun installer SIDIGIT (macOS,
Windows, APK Android) dari kode sumber privat dan menerbitkannya di
[SIDIGIT-23/sidigit-rilis](https://github.com/SIDIGIT-23/sidigit-rilis/releases/latest).
Unduh installer di sana. Lihat `.github/workflows/bangun.yml`.
